# نشر «دُلُّونِي عَلَى السُّوقِ» تطبيقًا قابلًا للتثبيت

## محتوى المجلد
| الملف | وظيفته |
|---|---|
| index.html | الكتاب نفسه، وهو الكتاب المستقل مع رابط التطبيق وتسجيل عامل الخدمة |
| manifest.json | تعريف التطبيق: الاسم، والاتجاه من اليمين، والألوان، والأيقونات |
| sw.js | عامل الخدمة: يحفظ الملفات عند أول فتح، ثم يعمل الكتاب دون اتصال |
| icons/ | أيقونات ١٩٢ و٥١٢ وأيقونة قابلة للقص (maskable) وأيقونة آيفون ١٨٠ |
| .nojekyll | يمنع GitHub Pages من معالجة الملفات |

## النشر على GitHub Pages
1. أنشئوا مستودعًا جديدًا، مثل `dulluni`.
2. ارفعوا **محتويات** المجلد إلى جذر المستودع، لا المجلد نفسه، بحيث يكون `index.html` في الجذر. الملف `.nojekyll` مخفي في بعض أنظمة التشغيل فتأكدوا من رفعه.
3. من Settings ثم Pages اختاروا: Deploy from a branch، ثم الفرع `main` والمجلد `/ (root)`.
4. بعد دقيقة أو اثنتين يعمل الرابط: `https://اسم-المستخدم.github.io/dulluni/`

المسارات كلها نسبية، فيعمل الكتاب تحت أي اسم مستودع أو نطاق خاص.

## التثبيت على الأجهزة
- **أندرويد (كروم):** افتحوا الرابط، ثم القائمة ⋮ ثم «تثبيت التطبيق».
- **آيفون (سفاري):** افتحوا الرابط، ثم زر المشاركة، ثم «إضافة إلى الشاشة الرئيسية».
- افتحوا الكتاب مرة واحدة متصلين بالإنترنت، وبعدها يعمل دون اتصال.

## تنبيهات مهمة
1. **التخزين مرتبط بالرابط:** تقدّم الأطفال وتسجيلاتهم محفوظة في الجهاز تحت هذا الرابط تحديدًا. إن غيّرتم اسم المستودع أو النطاق فلن تنتقل البيانات؛ صدّروا نسخة قبل ذلك.
2. **آيفون:** التطبيق المثبّت على الشاشة الرئيسية له تخزين منفصل عن سفاري. أنشئوا ملفات الأطفال من داخل التطبيق المثبّت، لا من سفاري. وسفاري قد يمسح بيانات المواقع غير المستعملة بعد سبعة أيام، والتثبيت على الشاشة الرئيسية يحمي منه.
3. **التحديث:** إذا عدّلتم الكتاب وأعدتم رفعه، يتغيّر رقم الإصدار في `sw.js` تلقائيًا عند البناء، فيُحمَّل الجديد في الخلفية ويظهر في الفتح التالي. ولا تُمَسّ التسجيلات ولا التقدّم.
4. **الخصوصية:** مستودعات GitHub Pages المجانية عامة. الكتاب لا يحوي بيانات شخصية، لكن **لا ترفعوا أبدًا الملفات المصدَّرة** إلى المستودع، ففيها أسماء الأطفال وأصواتهم.
5. **الميكروفون:** جرّبوا التسجيل داخل التطبيق المثبّت بعد تثبيته مباشرة على كل جهاز، فبعض إصدارات iOS القديمة تقيّد الميكروفون في التطبيقات المثبّتة.
6. **الملف المستقل** `دلوني-على-السوق.html` باقٍ كما هو للمشاركة دون استضافة.

## تطبيقا أندرويد وويندوز
يبنيهما GitHub Actions تلقائيًا (`.github/workflows/apps.yml`) عند كل تعديل في `source/` أو `apps/`، وتُنشر الملفات في صفحة **Releases** بالمستودع:
- **dulluni-souq-android.apk:** ملف واحد للهاتف والتابلت. الكتاب داخل التطبيق ويعمل دون اتصال من أول تثبيت. القراءة الآلية بمحرك النطق في أندرويد (يلزم وجود صوت عربي في إعدادات «تحويل النص إلى كلام»). التصدير يفتح نافذة المشاركة والحفظ. لا طباعة للشهادة داخل التطبيق.
- **dulluni-souq-setup.exe:** مُثبِّت ويندوز ١٠ و١١. القراءة الآلية بأصوات ويندوز (أضيفوا الصوت العربي من الإعدادات ← الوقت واللغة ← الكلام).
- **التوقيع:** APK موقّع بمفتاح ثابت محفوظ مشفّرًا في `apps/android/release.jks.enc`، وكلمة سره في السر `ANDROID_SIGNING_PASSWORD`؛ فالتحديث يُثبَّت فوق السابق وتبقى التسجيلات. ومُثبِّت ويندوز غير موقّع، فقد يظهر تحذير SmartScreen.
- بيانات كل تطبيق منفصلة عن الموقع وعن التطبيق الآخر.

## الصوت ووضع الوالدين
- بجانب كل نص زر 🔊. إن لم يوجد تسجيل فالقراءة الآلية، وإن وُجد ظهر زرّا «صَوْتِي» و«صَوْتُ أَهْلِي» ليختار الطفل.
- الطفل يسجّل الغلاف ونصوص صفحات القصة. والأهل يسجّلون كل نصوص الكتاب من «لِلْوَالِدَيْنِ ← تَسْجِيلُ الْكِتَابِ بِصَوْتِي».
- «لِلْوَالِدَيْنِ» محمي برمز من أربعة أرقام، وفيه: إضافة الأطفال وحذفهم، وحذف تسجيلاتهم، ونسخة للعرض، والنسخ الاحتياطي والاستعادة.
- نسيان الرمز: لا استعادة له من داخل التطبيق؛ يلزم مسح بيانات التطبيق، فاحتفظوا بنسخة احتياطية.
